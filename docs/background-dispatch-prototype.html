④ 会话历史里的状态标记（见左侧侧栏）

实心数字 badge = 该会话有已完成未读的后台 run，点开即清零，结果已在对话流里；
转圈数字 = 该会话还有 run 在跑；无标记 = 全部已读/无后台任务。Dashboard Workers tab 同步 busy/idle 分组。

落地要点（验收后实现）

  • run_agent 工具新增 background: true：入队立即返回 run id，卡片以 tool 事件流推给前端
  • 后台 run 完成后写回会话（结果摘要 + artifact），前端原位更新卡片；大脑下一轮自动带上下文验收
  • 并发策略：默认保持 1 个子进程；max_concurrent_agents 配置项放大队列（排队卡显示 queued）
  • 30 分钟单 run 超时不变；后台 run 超时/失败同样以卡片红色态 + 大脑汇报呈现
  • 侧栏 Chat badge = 未读完成数，进入对话即清零
